About

This is a web version of the LLM Chess Engine research project. Play as White — the engine plays Black. Set LLM_ENGINE_ENABLED=1 and provide the VICE engine binary to enable Llama-3 moves. Otherwise, a random move fallback is used.

Vercel demo: The hosted Vercel site runs this Flask app as a serverless function. Serverless instances cannot run the compiled VICE engine or a local Ollama server, so engine moves are random, and game/telemetry state resets when the instance spins down. To see LLM-powered moves, run locally with LLM_ENGINE_ENABLED=1 and a built VICE engine.

Research Question: Can constraining an LLM with a legal-move list eliminate hallucinated chess moves?
